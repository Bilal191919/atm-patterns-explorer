# 💳 ATM Transactions Data Analysis

> 📊 A complete end-to-end data analytics project exploring ATM transaction patterns, balance behavior, and data cleaning using Python.

---

## 🚀 Overview

This project dives into **ATM transaction data** to uncover key insights about customer behavior, transaction frequency, and cash balance patterns.  
It demonstrates **data cleaning, transformation, visualization, and export** — following a professional data analysis workflow.

The notebook provides a clean, step-by-step structure from raw dataset exploration to meaningful insights, designed for both **learning** and **portfolio showcasing**.

---

## 🧠 Objectives

- 🧹 **Clean and preprocess** real-world ATM transaction data  
- 🌐 **Translate and clarify** column names for readability  
- 📈 **Visualize transaction and balance trends**  
- 💾 **Export the cleaned dataset** for future use in analytics or ML pipelines

## 📋 Project Workflow

### **Step 1 — Data Import**
Load the dataset and essential libraries. Validate the structure and size of the raw data.

### **Step 2 — Dataset Preview 👀**
Explore the data: view column names, check datatypes, and detect missing or inconsistent values.

### **Step 3 — Data Cleaning & Translation 🧹**
Handle missing values, fix inconsistent formatting, and rename columns for better readability (including English translations if needed).

### **Step 4 — Clean Data Verification 📊**
Confirm cleaning results using `.head()`, `.info()`, and `.describe()` for a clearer dataset view.

### **Step 5 — Transaction Analysis 📈**
Visualize and analyze:
- Total number of transactions
- Transaction patterns over time
- ATM performance insights

### **Step 6 — ATM Balance Insights 💵**
Analyze and visualize ATM cash balance trends, withdrawals, and replenishment frequency.  
Includes corrected charts for accurate interpretation.

### **Step 7 — Data Export 💾**
Save the cleaned dataset for reuse — ideal for business intelligence or machine learning models.
